# my-sysadmin-scripts

Учебный проект по системному администрированию.

Проект начинался с Bash-скрипта мониторинга ресурсов системы, а затем был
контейнеризирован и развёрнут как HTTP-сервис за Nginx с HTTPS и systemd.

## Скрипт

`script.sh` три раза с интервалом 5 секунд собирает информацию о состоянии системы:

- использование оперативной памяти (`free -h`);
- использование файловых систем (`df -h`);
- время работы и среднюю нагрузку (`uptime`).

Результат сохраняется в `report.txt`.

При ошибке записи скрипт выводит сообщение в `stderr` и завершает работу с кодом ошибки.

## Что реализовано

- Bash-скрипт мониторинга ресурсов.
- Dockerfile для сборки образа.
- Docker Compose для проверки контейнеризации.
- HTTP-сервис внутри контейнера на порту 8080.
- RAID 1 на loop-устройствах.
- LVM: PV → VG → LV.
- Nginx как reverse proxy.
- HTTPS с self-signed TLS-сертификатом.
- systemd-служба для управления контейнером.
- Проверка логов через journalctl и логи Nginx.
